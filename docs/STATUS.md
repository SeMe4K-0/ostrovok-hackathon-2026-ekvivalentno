## НЕ проверено

- **GigaChat: качество и скорость.** На бесплатном тарифе параллельные запросы дают 429 (поэтому `GIGACHAT_MAX_CONCURRENCY=1`, есть повтор с паузой), `response_format: json_schema` портит вложенные схемы (по умолчанию выключен, JSON через промпт), модель иногда оборачивает ответ в `{"properties": …}` (разворачивается). Один ответ занимает 20–60 секунд (три вызова LLM на сообщение идут по очереди): для демо запрос лучше прогнать заранее. Сценарий выбора направления на живом ключе не доведён до списка направлений. Метрики `eval_scenarios.py` сняты на живом ключе (см. README, «Метрики качества»).
- **Корзина с живыми предложениями Туту**: перепроверка цены (`reprice` для отелей и транспорта) покрыта тестами с подставным MCP, но не прогонялась на живом сервере.
- **Стабильность Туту**: из сети разработки он то отвечал, то нет (`ConnectTimeout`); добавлены повторы, но поведение под нагрузкой жюри неизвестно.
- **Telegram-бот и Mini App вживую**: бот проверен тестами коллеги с подставным Telegram; запуск с настоящим токеном и открытие UI из Telegram по HTTPS не проверялись.
- Сборка и запуск на чужой машине и на нативном amd64 (проверено только на этом Mac через эмуляцию).

## Открыто

00. **Из аудита не закрыто:** F13 (трансферы: оценка времени и линия на карте, но нет вариантов, цены и позиции в корзине; конечная точка геометрии берётся от города, а не от отеля), F16 (в веб-интерфейсе нет экранов истории и шаблонов; подсказки по отелям не предлагаются автоматически после выбора направления). Остальные пункты «лишнего кода» из аудита (неиспользуемые поля, `base_revision` без вызова) оставлены сознательно: удаление по сканеру небезопасно.

0. **Цитаты отзывов и защита от инъекций на живой модели не проверялись.** Цитаты подбираются кодом по ключевым основам слов (без LLM), поэтому иногда выбирается не самое показательное предложение; фильтр атак узкий и не заменяет структурные ограничения (закрытые схемы, права операций, проверка чисел).

1. **Станции и аэропорты без координат.** Туту отдаёт только названия, координаты ищет геокодер (Nominatim): иногда не находит (аэропорт Нарита), тогда трансфер для этого узла не считается и на карте прямая линия между городами.
2. **Железной дороги Японии нет в Туту** (РЖД и автобусы только по России): Токио→Осака идёт самолётом. Отели Японии в Туту есть.
3. Мягкие текстовые пожелания (`free_text`: «тихо», «рядом с центром») не оцениваются: в плане и ответе честно написано, что они не проверяются автоматически (в плане был отдельный вызов LLM для этого).
4. Видео и ссылка на него в README, тег `submission` — перед сдачей.

| В плане | Сделано | Почему |
|---|---|---|

| цена: min-max по узлу | отношение «минимум / значение» | min-max превращал два варианта в 0 и 1 и позволял мелкой разнице цены перебить любой приоритет (поймано тестом) |
| ответ главного агента целиком от LLM | факты и структура «почему / компромисс / риск» строит код, LLM формулирует текст, числа проверяются | защита от выдуманных чисел |
